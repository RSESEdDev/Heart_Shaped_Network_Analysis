# Heart_Shaped_Network_Analysis
Turn your feedback or any other text into a heart shapped network analysis!

Included is an R project file with two .rmd files. The first one basically is to process the feedback (from doc files) into a csv and then manipulate it and also create a text graphic just to make sure it works.  The second file reruns some code and then generates the final image. 

I’ve included a sample feedback folder with some sample text (all of Jane Austen).  Note I’ve only used one feedback doc, you can put multiple files in there (all the same file type).  In the 1st .rmd file there are two choices based on this – only run the block of code to suit if you have 1 feedback file or more!

I’ve also included the output .csv files as examples.  Word_Counts.csv is generated by the first .rmd file.  You will need to manually add a column and add y or n to keep certain words about half way through.  I’ve also included community_words.csv and word_pairs_clean.csv as examples of the files generated, you can basically ignore those.

Finally there is the example final visualisation, its Jane Austen stress tested (hahaha).

Enjoy the data pretties.
